Mobile web validates URLs only. Installing still happens with gh-install on your computer.

Zero LLM tokens

This site and gh-install never send repository source to a chat model. The CLI shallow-clones with git and copies manifest files by filename. See VERIFY.md on GitHub.

First-time setup (desktop)

  1. Clone gh-install
  2. Windows: setup.cmd — Mac/Linux: chmod +x setup.sh && ./setup.sh
  3. gh-install --scan (or python3 gh-install.py --scan)

Allowed GitHub URLs

  • https://github.com/owner/repo
  • Optional /tree/ref/path or /blob/ref/file
